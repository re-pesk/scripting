# Scenarijai

Apvalkalų scenarijai (shell scripts) skirtingomis programavimo kalbomis ar jų dialektais. Tikslas - patikrinti, kaip skirtingos kalbos tinka rašyti operacijų sistemos valdymo scenarijus.

* [sys-upgrade](./sys-upgrade/readme.md "sys-upgrade") - Ubuntu paketų atnaujinimo scenarijus.

## Aplinkos parengimas

Programavimo kalbų ir vykdymo aplinkų [diegimas <sup>&#x2B67;</sup>](../install/proglangs/readme.md "Diegimas")
