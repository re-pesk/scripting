# Pagalbiniai scenarijai

* [alarm-clock](./alarm-clock/readme.lt.md) - priminimų skriptas
* [alternative-to-no-sandbox](./alternative-to-no-sandbox/readme.lt.md) - saugesnė alternatyva --no-sandbox parametrui, leidžiant AppImage failus.
* [app-launcher](./app-launcher/readme.lt.md) - būdas instaliuoti programas į atskirus katalogus, neužteršiant sistemos PATH kintamojo ir išvengiant apribojimų, kuriant įprastines simbolines nuorodas PATH kintamajame nurodytuose aplankuose.
* file-manager - failų tvarkyklių scenarijai

* install_helpers - pagalbiniai scenarijai, skirti programavimo kalbų ir jų vykdymo variklių diegimui
* [pandoc](./pandoc/readme.lt.md) - pandoc konverterio pagalbinis scenarijus
* [real-path](./real-path/readme.lt.md) - pagalbinės failų kelių paieškos funkcijos
* [script-loaders](./script-loaders/readme.lt.md) - scenarijų leidyklės
* [split-string](./split-string/readme.lt.md) - tekstų skaidymo funkcijos
