# Utility Scripts

* [alarm-clock](./alarm-clock/readme.en.md) - reminder script
* [alternative-to-no-sandbox](./alternative-to-no-sandbox/readme.en.md) - a safer alternative to the `--no-sandbox` flag when running AppImage files.
* [app-launcher](./app-launcher/readme.en.md) - a way to install applications into separate directories without cluttering the system `PATH` variable and avoiding the limitations of creating standard symbolic links in `PATH` directories.
* file-manager - file manager scripts
  * [Nautilus scripts](./file-manager/nautilus-scripts/readme.en.md)
  * [Nemo actions and scripts](./file-manager/nemo-scripts/readme.en.md)
* fix-php-fpm - troubleshooting scripts for PHP 8.\* FastCGI Process Manager (FPM)
* install_helpers - helper scripts for installing programming languages and their runtime environments
* [pandoc](./pandoc/readme.en.md) - helper script for the pandoc converter
* [real-path](./real-path/readme.en.md) - helper functions for resolving file paths
* [script-loaders](./script-loaders/readme.en.md) - script loaders / runners
* [split-string](./split-string/readme.en.md) - string splitting functions
